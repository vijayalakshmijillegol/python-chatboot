# Python Chatbot 🤖

## Project Description
This is a simple chatbot developed using Python. It interacts with users through text input and provides predefined responses to common questions.

## Features
- Greets the user.
- Answers simple questions.
- Provides basic information about Python.
- Displays the current time.
- Responds to thank-you messages.
- Exits when the user types "bye".

## Technologies Used
- Python
- VS Code

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python chatboot.py
```

6. Type your questions and interact with the chatbot.
